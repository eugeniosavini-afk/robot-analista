Conectá la API de YouTube

Robot Analista usa la API oficial de YouTube con tu propia clave gratuita. Se guarda solo en este dispositivo y no se envía a ningún otro servidor.

¿Cómo consigo la clave gratis? (5 minutos)
  1. Entrá a console.cloud.google.com con tu cuenta de Google. Es gratis y para esto no pide tarjeta.
  2. Arriba a la izquierda tocá el selector de proyecto → Proyecto nuevo → nombre: Robot Analista → Crear. Asegurate de que quede seleccionado.
  3. Menú ☰ → APIs y servicios → Biblioteca. Buscá YouTube Data API v3 y tocá Habilitar.
  4. Menú ☰ → APIs y servicios → Credenciales → + Crear credenciales → Clave de API. Copiá la clave (empieza con AIza).
  5. Recomendado: en la clave tocá Editar → Restricciones de API → Restringir clave → marcá solo YouTube Data API v3 → Guardar.
  6. Pegala arriba y tocá Guardar y probar.

Cuota gratis: 10.000 unidades por día. Cada canal analizado usa unas 3 unidades, así que alcanza para cientos de análisis diarios.
